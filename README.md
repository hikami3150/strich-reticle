# 第二次世界大戦ドイツ戦車照準器シミュレーター (WWII German Tank Gunsight Simulator)

第二次世界大戦期のドイツ戦車に搭載されていた照準器（**Turmzielfernrohr: TZF**）をスマートフォンのブラウザ上で再現するWebアプリケーションです。

スマートフォンの背面カメラのリアルタイム映像に透過レティクルを重ね合わせることで、3Dプリント等で自作した照準器レプリカに組み込んで覗き込んだり、歴史資料の学習・展示で当時の戦車砲手の視野を体験できます。

---

## 🌟 主な特徴

1. **4種類の歴史的照準器を再現**:
   * **TZF 9b** — ティーガーI (Panzerkampfwagen VI Tiger I / 8.8 cm KwK 36)
   * **TZF 9d** — ティーガーII (Panzerkampfwagen VI Ausf. B King Tiger / 8.8 cm KwK 43)
   * **TZF 12a** — パンター (Panzerkampfwagen V Panther / 7.5 cm KwK 42)
   * **TZF 5b** — IV号戦車 (Panzerkampfwagen IV / 7.5 cm KwK 37 短砲身)
2. **完全端末内処理（プライバシー完全保護）**:
   * カメラ映像はすべてお使いのスマートフォンのブラウザ内だけでリアルタイム処理されます。
   * サーバーへの画像・動画の送信や保存は一切行われません。
3. **レプリカビュー (Replica View)**:
   * 実物の照準鏡筒内部を覗き込んでいるかのような、外側ブラックアウトの円形アイピース視野とレンズ減光（ビネット）を表現。
4. **照準器ごとの個別キャリブレーション & 永続化**:
   * 位置（上下左右オフセット）、大きさ（スケール）、透明度、明るさ、カラー（白 / アンバー / 緑）を照準器ごとに調整可能。
   * 設定はブラウザ（`localStorage`）に照準器ごとに個別保存されます。
5. **展示・レプリカ用「Museum Mode」**:
   * 自作レプリカや博物館展示において余計なUIを排除し、視界に没入できるミニマルモード。
6. **ゼロビルド & GitHub Pages 対応**:
   * WebpackやNode.js等のビルド手順は不要。リポジトリにアップロードしてGitHub Pagesを有効化するだけで、スマホから即座にアクセスして利用可能。

## 🚀 使い方・GitHub Pagesでの公開手順

### 1. GitHub Pagesへのデプロイ
1. このリポジトリの全ファイルをGitHubのリポジトリにコミット＆プッシュします。
2. GitHubのリポジトリ設定（Settings）→ **Pages** を開きます。
3. **Branch** で `main`（または `master`）の `/ (root)` を選択し、**Save** をクリックします。
4. 発行されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマートフォンのブラウザ（SafariまたはChrome）で開きます。

### 2. スマートフォンでの操作
1. 画面中央の「**カメラを開始**」をタップし、カメラの利用を許可します。
2. 画面右上のギアアイコン（設定）をタップすると、各種調整メニューが開きます。
3. **照準器モデル**: ドロップダウンから体験したい照準器を選択します。
4. **レプリカビュー**: 3Dプリントレプリカにスマートフォンを装着する場合は、視野円の直径をレプリカのアイピース開口に合わせて調整してください。
5. **キャリブレーション**: 方向ボタン（▲▼◀▶）でレティクルの中心位置をカメラのレンズ位置に合わせます。

## 🔍 歴史的資料に関する注記 (Historical Approximation)

本アプリに登場するレティクルの目盛り（Strich / Stachel / 距離目盛り）は、第二次世界大戦時の現存資料・軍教本（H.Dv.）・写真・光学図面に基づいて再現されています。現存資料のみでは詳細が確定できない部分については、現代的な創作要素を追加せず「史料に基づく近似（Historical approximation）」として扱っています。

### 重要なお知らせ
本アプリは**歴史学習・教育展示・自作レプリカ鑑賞専用**のシミュレーターです。実際の武器使用、弾道計算、射撃予測等を行う機能は意図的に排除されており、それらに転用することはできません。
